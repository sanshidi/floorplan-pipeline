户型临摹工作台

上传户型图 → 标定比例 → 描摹墙体 → 选材质 → 2D/3D 布置 → 按真实面积估造价

纯浏览器 · 可校准临摹
业主流程 上传户型图后，设计器默认按你的图空白临摹（不自动识墙）。依次：标定真实尺寸 → 画墙 → 放门窗 → 识别房间估造价 → 布置家具与 3D 漫游。也可点「从样板开始」用内置三居室试用。
① 上传图纸 ② 选材质 ③ 临摹墙体 ④ 布置 · 3D ⑤ 看造价导出

1. 上传户型图

支持 PNG / JPG / WEBP。图片仅保存在本机浏览器，不会上传到服务器。上传后进入设计器，即可对着底图标定与描墙。

拖拽图片到此处，或点击选择文件
建议清晰的平面户型图，便于对照描摹与布置

2. 起步方式与房间

上传了图纸时，默认「按我的图临摹」。若只想试用，可选「从样板开始」。下方房间勾选主要用于套用地面材质；自建墙后点「识别房间」会按封闭区域重算面积与造价。

4. 临摹与设计

设计器顶栏：有底图时点「按我的图临摹」，再标定 → 画墙 → 放门窗 → 识别房间。可用「底图在上」对照描摹。完成后拖家具、看造价，切 3D；漫游前需有入户门。

标定比例点外墙长边两端填 mm；无尺寸可改用建筑面积㎡反推
画墙 / 门窗连续折线画墙（回车结束）；默认15°磁吸，Shift=斜墙；再点墙放门窗
识别房间按封闭区域生成面积，供造价使用
从样板开始随时加载内置三居室墙体试用

设计器同源嵌入（./editor.html）。若 iframe 过矮，可用「新标签打开」获得全屏体验，数据仍写回同一本机浏览器。
