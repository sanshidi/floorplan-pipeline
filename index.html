户型生成工作台

上传户型图 → 选房间与材质 → 本页 2D/3D 布置家具 → 造价与导出

纯浏览器 · 无需外链工具
关于第一版 不会自动从图纸识别墙体。上传的户型图作为参照底图；墙体与房间使用内置可编辑样板（来自 floorplan-3d），你在本页完成家具、材质、测量、拆改非承重墙、3D 漫游与导出。

1. 上传户型图

支持 PNG / JPG / WEBP。图片仅保存在本机浏览器 localStorage，不会上传到服务器。

拖拽图片到此处，或点击选择文件
建议清晰的平面户型图，便于对照描摹与布置

2. 选择房间 / 样板

使用内置三居室样板（可测、可拆非承重墙）。勾选你关心的房间，进入设计器后可为它们统一套用材质。

样板房间

3. 地面 / 墙面材质

列表来自 OpenPlan3D 与 floorplan-3d 的真实材质目录。地面带单价，进入设计器后按面积 ×1.05 损耗估算造价。

地面材质（单选 · 将应用到已选房间）

墙面材质（单选 · OpenPlan3D 墙漆/贴面）

4. 本页设计器

下方嵌入完整 2D 布置 + Three.js 3D 漫游。左侧拖家具，右侧改材质与造价，顶栏可导出 PNG/JSON。上传的户型图会作为 2D 参照底图。

设计器同源嵌入（./editor.html）。若 iframe 过矮，可用「新标签打开」获得全屏体验，数据仍写回同一 localStorage。

5. 结果与导出

作业状态保存在 localStorage['floorplan-pipeline-v1']；设计方案保存在 huxing-design-v1。

作业 JSON

PNG 导出请在设计器顶栏「文件 → 导出图片」完成（2D 或 3D 截图）。
